# Dataset

[Dataset link — Seoul Data Hub](https://data.seoul.go.kr/bsp/wgs/dataView/data300View/645.do)

This project uses the CSV file **[서울교통공사] 지하철혼잡도 정보.csv** for data processing. Since the dataset doesn't provide JSON format, we'll use the CSV file. Below are the column names.

## CSV structure

Data: **23,316 x 46**

The file contains six descriptive columns, 39 half-hour congestion columns, and one `분기` (quarter) column.

## Unique values by column

A blank cell and `-` are treated as missing values for descriptive columns. No values are inferred or filled in yet.

| Column (Korean) | Field name | Unique values found in CSV | Missing values |
| --- | --- | --- | --- |
| 년도 | `yr` | 2017, 2019, 2021, 2022, 2023, 2024, 2025, 2026 | None |
